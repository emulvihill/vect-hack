# Third-party notices

Notices for the third-party components bundled into the built application.
Bundlers strip license comments, so the required notices live here.

This file covers **bundled runtime components only**. Each game engine keeps
its own license — see [LICENSING.md](LICENSING.md) for the map, and
[LICENSE.NETHACK](LICENSE.NETHACK), [LICENSE.GPL2](LICENSE.GPL2),
[LICENSE.GPL3](LICENSE.GPL3), and [LICENSE.LARN](LICENSE.LARN) for their
texts. `npm run build` copies all of them into `dist/licenses/`, so a copied
`dist/` carries its own terms.
