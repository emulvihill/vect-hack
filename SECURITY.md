# Security

Report a vulnerability privately through GitHub: the repository's
**Security** tab, **Report a vulnerability**. Please do not open a public
issue for it.

Only the latest release and `main` get fixes. The game engines (NetHack,
Angband, Larn, Umoria) are upstream code built unmodified; a flaw in one of
them belongs with its upstream project, though a report here is welcome when
VectHack's build or I/O layer makes it reachable.
